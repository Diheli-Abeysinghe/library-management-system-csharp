# Library Management System

A console-based Library Management System developed in C# to practise object-oriented programming and verify application behaviour through unit testing.

## Overview

This project models a simple library environment using `Book`, `Member`, and `Library` classes. It implements borrowing rules and demonstrates how object-oriented design can be combined with automated unit tests to check that application logic behaves as expected.

## Features

- Book and member management.
- Library borrowing rules.
- Object-oriented design using encapsulation, inheritance, and polymorphism.
- Automated unit testing using MSTest.

## Technology Stack

- **Language:** C#
- **Testing framework:** MSTest
- **Application type:** Console application
- **Concepts:** Object-oriented programming, unit testing, software verification

## Testing

The project includes 24 MSTest unit tests designed to verify application behaviour and borrowing rules.

The test suite provides practical experience with automated verification, expected outcomes, and identifying potential defects.

### Running the tests

1. Install the .NET SDK compatible with the project.
2. Open the solution in Visual Studio, or navigate to the solution directory in a terminal.
3. Run:

   ```bash
   dotnet test
   ```

4. Review the test results to identify passed and failed tests.

## Getting Started

Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/library-management-system-csharp.git

```

Open the solution in Visual Studio and run the console application.
